# Quotation App — Admin Dashboard

Admin Web Dashboard for the Product Quotation platform for **Ganesh Gouri Industries Pvt Ltd**.

---

## 🌐 Live Admin Panel

🔗 **Live URL:** [https://quotation-app-admin.onrender.com](https://quotation-app-admin.onrender.com)

Hosted on [Render](https://render.com).

---

## 🛠️ Tech Stack

- **Framework:** Next.js
- **Styling:** Tailwind CSS & Lucide Icons
- **Deployment:** Render

---

## 🚀 Getting Started Locally

### 1. Install Dependencies
`ash
npm install
`

### 2. Run Development Server
`ash
npm run dev
`

Open [http://localhost:3000](http://localhost:3000) in your browser.

### 3. Build for Production
`ash
npm run build
npm start
`
